# Portfólio — Vinicius Lopes

Portfólio pessoal desenvolvido como projeto acadêmico para praticar HTML, CSS e JavaScript.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Estrutura
```text
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── img/
│   └── perfil.svg
└── README.md
```

## Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências.

## Objetivo
Apresentar minha trajetória de aprendizagem em Engenharia de Software e reunir projetos desenvolvidos durante meus estudos.
